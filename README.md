## What I'm building now

<table>
<tr>
<td width="50%" valign="top">

### MatrixOS

My own OS project. Current work is around the graphics stack and real hardware support rather than just running inside an emulator.

`kernel` `GPU bring-up` `NVIDIA Ampere` `OpenGL` `Vulkan` `USB/HID`

**Status:** active · private for now

</td>
<td width="50%" valign="top">

### MatrixMessenger

Messenger backend with an E2EE protocol implementation. The interesting part for me is the protocol and key lifecycle, not another chat UI.

`FastAPI` `X25519` `Double Ratchet` `SQLAlchemy` `Alembic`

**Status:** active · private

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Small LLM experiments

Training compact transformer models on consumer hardware and squeezing as much as possible out of limited VRAM.

`PyTorch` `GQA` `RoPE` `QK-Norm` `BF16` `custom tokenizer`

**Current scale:** ~135M parameters

</td>
<td width="50%" valign="top">

### Hardware / embedded

I like projects where code eventually has to move something physical: ESP32, sensors, control electronics, prototyping and soldering.

`ESP32` `Bluetooth` `electronics` `prototyping`

</td>
</tr>
